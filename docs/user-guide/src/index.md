# Diorama User Guide

Diorama is a GNOME image viewer and focused editing workspace. It lets you
browse a sequence, inspect pixels, compare related images, make reversible
edits, and export a result. Your source image stays unchanged until you save
or export.

[![Diorama displaying a fantasy character sample with its browsing controls](assets/screenshots/overview.png)](assets/screenshots/overview.png)

*Diorama opens the character artwork at a useful scale while keeping browsing
and editing actions close by. Select the image to view it at full size.*

Use this guide by task. Start with [opening and browsing images](getting-started.md),
then choose [inspection](inspect.md), [comparison](compare.md),
[editing and annotation](edit-and-annotate.md), or [export](save-and-export.md).

The screenshots use a small fantasy-character sample set. They demonstrate the
app's tools; the sample artwork is not included with Diorama or this guide.
