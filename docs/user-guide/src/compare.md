# Compare two images

1. Open the primary image.
2. Choose **Tools → Compare Images…** or press <kbd>D</kbd>, then choose the
   second image.
3. Keep synchronized views enabled, then pan or zoom one side to inspect the
   same relative area in both images.
4. Press <kbd>L</kbd> to show paired lenses at the matching relative position.

Diorama chooses a side-by-side or stacked layout according to the image shapes.
The comparison image is read-only; the normal reversible editing tools still
apply to the primary image. If either source changes on disk, Diorama refreshes
the affected display. Save work on the primary image before replacing it.

[![Comparison view with matching inspection lenses over two fantasy-character images](assets/screenshots/compare-lenses.png)](assets/screenshots/compare-lenses.png)

*The paired lenses reveal corresponding detail on both character images.
Select the image to view it at full size.*

With the paired lenses visible, Shift+scroll changes their size and Alt+scroll
changes their magnification. Each side shows its file location and resolution
so that similar-looking files remain distinguishable.

Comparison view starts synchronized. Turn synchronization off in the comparison
controls when you need to inspect different areas independently. The **Hard
zoom** and transparency-background preferences apply to both sides.
