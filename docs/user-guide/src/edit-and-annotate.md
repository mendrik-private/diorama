# Edit and annotate

Diorama keeps the source image unchanged while you work. Completed edits are
operations in the current document: undo with <kbd>Ctrl</kbd>+<kbd>Z</kbd>,
redo with <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>, then save or export when
the result is ready. Saving or exporting PNG/JPEG writes a flattened raster;
it cannot restore individual annotation objects in a later session. Perform
finishing tools that flatten annotations last, or undo back to an earlier
document state while this session remains open.

## Choose the task

- [Crop and select](cropping.md) for exact rectangles, detected content, copy,
  or background fill.
- [Transform](transformations.md) for rotate, flip, square canvas, canvas
  resize, and Warp Mesh.
- [Remove or move a background subject](background-removal.md) for cutouts and
  pasted image objects.
- [Draw and annotate](drawing-and-annotations.md) for pencil, highlights,
  arrows, curved text, and measurements.
- [Scale](scaling.md) and [Scale game assets](game-asset-scaling.md) for output
  dimensions and resampling.
