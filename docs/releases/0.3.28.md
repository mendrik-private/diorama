# Diorama 0.3.28 release preparation

Prepared on 2026-10-30 from `main`, using `v0.3.27` (`9f22d5e`) as the
previous release. The release notes will record the final main revision and
successful GitHub Pages workflow and deployment URL before tagging.

## Change review and capability coverage

Every change since `v0.3.27` was reviewed. Copy Filepath moves out of File
to the first row of the hamburger menu. Open Location follows it and opens
the current local file in its parent folder through GTK's file-manager
launcher. The original File, Tools, Edit, Transform, and Info groups follow.
Open Location is disabled without a loaded local image with a parent folder;
cancellation is ignored and launcher failures produce a toast. No keyboard
shortcut changes.

The user-facing capability matrix was checked against this change set. The
main-menu/file capability changes affect [Get started](../user-guide/src/getting-started.md),
which now documents the two direct actions, folder behavior, and disabled
states. Save/export and clipboard-image procedures keep their existing menu
paths. All other capability rows are intentionally unchanged: image formats,
sequence navigation, playback, inspection, comparison, drawing, transforms,
scaling, background removal, preferences, export behavior, and model setup.

## Screenshot evidence

`main-menu.png` captures the real open menu at normal display density with
the current image loaded. Screenshot provenance and reproduction instructions
are in [the capture record](../../data/screenshots/guide/README.md). Existing
captures do not show an open hamburger menu and remain accurate.

## Verification

The updated menu-order test checks both direct actions and every existing
submenu item. The normal native test suite and formatting pass. Native
Clippy reports pre-existing warnings in unchanged code with Rust 1.99.
The release also requires the real menu capture, the documentation build
and link/image checks, and the local Flatpak build/install. Their results
are recorded in the release notes after execution.
