# Diorama 0.3.27 release preparation

Prepared on 2026-10-27 from `main`, using `v0.3.26` as the previous release.
Before `v0.3.27` is created or pushed, the release owner must verify that the
successful GitHub Pages deployment is for the final main revision. The exact
revision, workflow run, and deployed
[`https://mendrik-private.github.io/diorama/`](https://mendrik-private.github.io/diorama/)
URL belong in the GitHub release notes, avoiding a self-referential commit that
changes the revision being verified.

## Change review

Every commit after `v0.3.26` was reviewed:

- `72f71cd` opens WebM files through GTK's built-in GStreamer media backend.
  Clips play muted and looping with the existing previous-frame, play/pause, and
  next-frame controls; stepping seeks by the observed frame interval. Pausing or
  stepping makes the displayed frame the editable source. Choosing a drawing
  tool, applying an edit, saving, copying, or printing pauses playback first.
  Playback is disabled while the frame has edits. Folder navigation includes
  `.webm`, and the desktop file lists `video/webm`.
