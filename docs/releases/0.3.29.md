# Diorama 0.3.29 release preparation

Prepared on 2026-11-15 from `main`, with `v0.3.28` (`c0699db`) as the
previous release. The final main revision and its successful GitHub Pages
workflow and deployment URL are recorded in the published release notes
before the release is finalized. Pages must succeed for that revision before
the tag is created.

## Change review and capability coverage

Every change since `v0.3.28` was reviewed. On an uncached Game Asset request,
Diorama now provisions an absent Python environment and missing FLUX pipeline
and Q4_K_M transformer before inference. It shows the downloading stage,
allows cancellation, reuses completed files, and checks the pinned revision,
GGUF size, and verified hash marker before inference. A damaged GGUF without
a valid marker is downloaded again and hashed. Cache hits continue to bypass
runtime resolution. Setup is serialized across windows without holding the
GPU inference permit during downloads. Flatpak uses host-launched setup with
explicit, host-visible model paths and can reuse verified host model files.
The inference worker remains offline. Host GPU-enabled PyTorch and access to
the gated Hugging Face repository are still prerequisites; access failures
explain licence acceptance and authentication.

The capability matrix in `docs/documentation-plan.md` was checked. Model setup
and Game Asset scaling affect [Set up local models](../user-guide/src/model-setup.md),
[Scale game assets](../user-guide/src/game-asset-scaling.md), and the
[troubleshooting guide](../user-guide/src/shortcuts-and-troubleshooting.md).
These pages cover first use, progress, cancellation, retry, storage, runtime
requirements, and authentication errors. The README and attribution notice
also describe automatic setup.

All other entries intentionally remain unchanged: file and menu actions,
formats and sequence navigation, video/animation playback, zoom and lenses,
comparison, selection and background removal, annotation, transforms and mesh,
canvas resize, ordinary scale methods, Game Asset rendering and strength,
preferences, save/export, printing, keyboard shortcuts, and the unavailable
palette entry. There are no new shortcuts or changes to final image output.

## Verification

Native formatting, compilation, the full test suite, the nine offline Python
setup tests, AppStream validation, and the guide build with link/image checks
are required. Regression coverage includes missing dependencies before
production generation, verified reuse, partial installs, corrupt hashes,
network and access errors, cancellation, and the Flatpak host bootstrap path.
Clippy on Rust 1.99 has existing warnings in unchanged code; the earlier strict
run failed on those warnings, with no changes made to unrelated source.

The user-local Flatpak master branch was built and installed as 0.3.29. The
host runtime setup installed the pinned Python packages while preserving
PyTorch 2.9.1 with ROCm, and its probe detected the AMD Radeon 8060S GPU. The
published stable bundle is installed locally after the tagged workflow
succeeds and its checksum is verified. Final test counts, workflow URLs,
checksums, and any remaining model-download or inference limitations are
recorded in the release notes.
